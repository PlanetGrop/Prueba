SIN DESCARGAS DEL NAVEGADOR

Llévalo a Windows

Este bloque crea una carpeta nueva Clave-… en tu Escritorio con el proyecto completo. No incluye tus contraseñas, no sobrescribe proyectos y no publica nada.

  1. Copia el bloque completo con el botón de abajo.
  2. Abre Windows PowerShell desde Inicio.
  3. Pega el bloque y pulsa Enter. Si Windows Terminal pide confirmar un pegado de varias líneas, revisa el bloque y acepta para ejecutarlo.
  4. Cuando termine, ejecuta npm ci y después npm start. Requiere Node.js 24 LTS.
  5. Escribe http://localhost:3000 en Chrome.

Preparando el proyecto…

Si la copia está bloqueada, pulsa Seleccionar texto y luego Ctrl+C. No necesitas descargar archivos ni cambiar la política de ejecución de PowerShell.
